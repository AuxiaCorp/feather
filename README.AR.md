# Feather Language — نظام إقلاع مستقل للاستضافة الذاتية (v8، تجريبي)

هذا المجلد شجرة مصدر لنظام إقلاع جديد لمصرّف Feather، خالية من Rust والتبعيات الخارجية. وهو ليس بديلاً عن جميع ميزات لغة V7. يجب الاحتفاظ بأرشيف V7 العامل بشكل منفصل إلى أن تتحقق المطابقة الوظيفية.

## وظائف تم التحقق منها وقابلة للتشغيل

يوجد تنفيذ المصرّف في `src/compiler.feather` (مجموعة فرعية لنظام إقلاع Feather، نحو 2300 سطر). يتعرف على الرموز والأسطر، ويفك ترميز المعاملات العددية، ويحلّ فروع الانتقال الأمامية والخلفية بنيوياً، ويصدر مباشرة تعليمات آلة x86-64 وترويسات Linux ELF64.

يقوم البرنامج التمهيدي الأصلي لـ x86-64 (`bootstrap/feather-seed`) بترجمة مصدر Feather هذا إلى مصرّف أصلي ثانٍ. ثم يترجم المصرّف الناتج المصدر نفسه لإنتاج مصرّف ثالث. الأجيال المتكررة متطابقة بايتاً ببايت ولها قيم SHA-256 متطابقة.

### `.feather -> .fthr`

في نظام الإقلاع هذا، `.fthr` ملف تنفيذي Linux ELF64 بامتداد `.fthr`، وليس حاوية V7 السابقة `FTHRNAT2`. يعمل البرنامج مباشرة على Linux لأن ELF حاوية أصلية لنظام التشغيل.

لا يلزم مفسّر أو Rust أو Cargo أو Python أو Clang أو GCC أو LLVM أو glibc أو JVM لبناء هذه البرامج أو تشغيلها. لم يُنفّذ دعم Windows أو ARM64 أو التوافق مع تنسيق V7.

يجب أن يكون السطر الأول `#terminal-only` أو `#executable` أو `#script`. ويجب أن يكون السطر الأخير `quit.script` متبوعاً بمحرف سطر جديد. تنتج الأوضاع الثلاثة حالياً نموذج دخول Linux ELF واحداً موجهاً إلى وحدة التحكم؛ ولم تُنفّذ دلالات أذونات GUI/النوافذ.

### ELF والأمان

ملف ELF مرتبط ربطاً ثابتاً، دون محمّل ديناميكي، ويحتوي على مقاطع منفصلة للقراءة/التنفيذ والقراءة/الكتابة، مع مكدس غير قابل للتنفيذ. يستخدم ELF الحالي النوع `ET_EXEC`، ولا يدعم PIE/ASLR. لا تتوفر بيئة عزل لكود المستخدم.

تستخدم حسابات السجلات أعداداً صحيحة من 64 بت مع التفاف عند تجاوز المجال (wrapping). لا يوجد نظام أنواع كامل أو فحص تلقائي للحدود.

## البناء دون سلسلة أدوات ترجمة

على Linux x86-64، ومن هذا المجلد:

```sh
./scripts/build.sh
./scripts/test.sh
./bin/feather examples/hello.feather examples/hello.fthr
./examples/hello.fthr
```

أو:

```sh
make build
```

يلزم لتشغيل المصرّف فقط برنامج البذرة ذي الشيفرة الآلية x86-64 المبني مسبقاً، ومصدر Feather، واستدعاءات نظام Linux القياسية. تستخدم سكربتات shell الاختيارية للبناء والاختبار bash وأدوات النظام الأساسية. لا توجد تبعيات وقت تشغيل على سلاسل أدوات ترجمة اللغات. هذا ليس نظام إقلاع متعدد المنصات.

### التثبيت

للتثبيت في `~/.local/bin`:

```sh
./scripts/install-linux.sh
```

عيّن `PREFIX=/custom/path` لاستخدام وجهة أخرى.

تقبل واجهة CLI الأصلية حالياً وسيطين موضعيين:

```sh
feather SOURCE.feather OUTPUT.fthr
```

لم تُنقل بعد أوامر V7 الكاملة مثل `feather build --maximum` و`feather inspect` و`feather lib`. ولا يُدعم استدعاء `./bin/feather` بوسائط غير مدعومة.

## صياغة نظام الإقلاع المنفذة

القواعد النحوية محدودة عمداً:

```feather
#terminal-only
Working=demo
set r01=0000000000000000
set r02=0000000000000003
while r01<r02 [
say"Hello"
inc r01
]
quit.script
```

تقتصر المتغيرات على 100 خانة سجلات من 64 بت بأسماء `r00..r99`. يقبل `set` ستة عشر رقماً سداسياً عشرياً صغيراً بالضبط. لا يدعم بعدُ معرّفات المصدر الاعتباطية مثل `set enabled=true` في V7.

العمليات: `copy r01=r02`، `inc r01`، `dec r01`، `add r01=r02`، `sub r01=r02`، `mul r01=r02`.

الشروط: `when r01==r02 [`، `when r01!=r02 [`، `when r01<r02 [`، `when r01>=r02 [`.

الحلقات: `while r01<r02 [`، `while r01!=r02 [`، `while r01==r02 [`؛ وتُغلق الكتل باستخدام `]` في سطر مستقل.

### الإخراج والملفات والمخازن الثنائية

- `say"ASCII/UTF-8 text"` — يطبع النص دون تفسير تسلسلات الهروب أو دعم علامات الاقتباس المضمّنة.
- `load source` — يقرأ مُدخل argv إلى مخزن مصدر ثابت ويضبط `r00` على طوله بالبايت.
- `store output rXX` — يكتب الناتج الثنائي إلى مسار argv التالي.
- `get r01=source[r02]` — يقرأ بايتاً واحداً.
- `get32 r01=output[r02]` — يقرأ قيمة من 32 بت.
- `put output[r01]=r02` — يكتب بايتاً واحداً.
- `put32 output[r01]=r02` — يكتب قيمة من 32 بت.
- `put64 output[r01]=r02` — يكتب قيمة من 64 بت.
- `append r01="48454c4c4f"` — يضيف بايتات محددة بتمثيل سداسي عشري بأحرف صغيرة.
- `fail` — ينهي التنفيذ بحالة خروج 2.

تعليمة واحدة في كل سطر. يجب أن تكون نهايات الأسطر LF وأن ينتهي السطر الأخير بـ LF. يتم التعرف على تعليقات `""` في بداية السطر وتراكيب `Working=...`. لم تُنقل صياغة V7 العامة بعد.

هذه مجموعة فرعية للترحيل، وليست ادعاءً بالتوافق الكامل مع صياغة Feather.

## بنية المصرّف

كُتب المصرّف بلغة Feather ويستضيف نفسه، لكنه ينفذ حالياً خفضاً مباشراً بمرور واحد (direct one-pass lowering). لا تزال AST عامة، ومحلل دلالي، ومحسّن، وأنواع عامة، وIR غير منفذة.

## التحقق

يفحص `./scripts/test.sh` تطابق ثلاثة أجيال من البناء الذاتي بايتاً ببايت، وتنفيذ ELF الأصلي، والحسابات والحلقات أثناء التشغيل، وعمليات المخازن الثنائية 32/64 بت، ونسخ الملفات بما فيها بايتات NUL و`0xff`، وأخطاء إدخال/إخراج الملفات، ورفض المصدر غير السليم، وبيانات المكدس غير القابل للتنفيذ. لا تستخدم الاختبارات Rust أو أي مصرّف لغة آخر.

### البذرة وجذر الثقة

البذرة برنامج شيفرة آلة مترجم مسبقاً ويعمل بوصفه جذر الثقة. أُعدّت في البداية خارج شجرة المصدر هذه. بعد البناء الأول، يمكن إعادة إنتاج المصرّف بالكامل من `src/compiler.feather` باستخدام ملف Feather تنفيذي بُني ذاتياً سابقاً.

يثبت تطابق التجزئات بين الأجيال إعادة التوليد الحتمية على البنية التي جرى اختبارها. لكنه لا يثبت غياب السلوك الضار أو سلامة الذاكرة أو التحصين الإنتاجي.

## خطوات الترحيل الحرجة المتبقية

احتفظ بأرشيف V7 القديم للوظائف التاريخية. لا يدعم فرع الاستضافة الذاتية الأصلي بعدُ المتغيرات المسماة/Bool/التعبيرات النصية، وlexer/AST/نظام الأنواع/IR الكامل، والعروض العددية ذات الأنواع، وتشخيصات المصرّف مع مواضع المصدر، وفحص تجاوز الأعداد الصحيحة الموقعة، وضمانات إدارة ذاكرة آمنة دون GC، والفحص التلقائي للحدود، وasync، ومدير الحزم/98 مكتبة، و`Number.by`، وTLS/الشبكات، وGUI/Blender/3D، وFFI، وتنسيق `FTHRNAT2`، والتواقيع، وARM64، وWindows، واختبار fuzz/مراجعة الأمان.

**لا تنشر هذا الإصدار بوصفه مصرّفاً موثوقاً للتعامل مع مصدر غير موثوق.** إنه أساس أصلي تم التحقق من قدرته على الاستضافة الذاتية، وليس توزيعة لغة جاهزة للاستخدام الإنتاجي.
