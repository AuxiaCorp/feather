# Feather Language — Тәуелсіз өзін-өзі құрастыратын бастапқы жүктеу жүйесі (v8, эксперименттік)

Бұл бума — Rust пен сыртқы тәуелділіктерсіз жаңа Feather компиляторының бастапқы жүктеу жүйесіне арналған бастапқы кодтар ағашы. Ол V7 тілінің барлық мүмкіндіктерін алмастырмайды. Функционалдық сәйкестікке жеткенше, жұмыс істейтін V7 архивін бөлек сақтау қажет.

## Тексерілген, іске қосылатын мүмкіндіктер

Компилятор `src/compiler.feather` файлында орналасқан (Feather бастапқы жүктеу ішкі жиыны, шамамен 2300 жол). Ол токендер мен жолдарды таниды, сандық операндтарды декодтайды, алға және артқа тармақталуларды құрылымдық түрде шешеді, x86-64 машиналық нұсқауларын және Linux ELF64 тақырыптарын тікелей шығарады.

x86-64 нативті бастапқы нұсқасы (`bootstrap/feather-seed`) Feather бастапқы кодын екінші нативті компиляторға құрастырады. Ол компилятор сол кодты үшінші компиляторға құрастырады. Қайталанған буындар байт-байт бойынша бірдей және SHA-256 хэштері де бірдей.

### `.feather -> .fthr`

Бұл нұсқада `.fthr` — бұрынғы V7 `FTHRNAT2` контейнері емес, `.fthr` кеңейтімі бар Linux ELF64 орындалатын файлы. ELF операциялық жүйенің нативті контейнері болғандықтан, бағдарлама Linux жүйесінде тікелей іске қосылады.

Құрастыру және орындау үшін интерпретатор, Rust, Cargo, Python, Clang, GCC, LLVM, glibc немесе JVM қажет емес. Windows, ARM64 және V7 пішімімен үйлесімділік іске асырылмаған.

Бірінші жол міндетті түрде `#terminal-only`, `#executable` немесе `#script` болуы керек. Соңғы жол `quit.script` болып, одан кейін LF жаңа жол таңбасы келуі керек. Үш режим де қазір консольге арналған бірдей Linux ELF кіру моделін жасайды; GUI/терезе рұқсаттарының семантикасы іске асырылмаған.

### ELF және қауіпсіздік

ELF статикалық түрде байланыстырылған, динамикалық жүктеушісі жоқ, оқу/орындау және оқу/жазу сегменттері бөлек, стегі орындалмайды. Қазіргі ELF — `ET_EXEC`, PIE/ASLR қолдамайды. Пайдаланушы коды үшін sandbox жоқ.

Регистр арифметикасы 64-биттік бүтін сандарды циклдік толып кету семантикасымен пайдаланады. Толық типтер жүйесі және шекараларды автоматты тексеру жоқ.

## Компилятор құралдарынсыз құрастыру

Linux x86-64 жүйесінде осы бумадан:

```sh
./scripts/build.sh
./scripts/test.sh
./bin/feather examples/hello.feather examples/hello.fthr
./examples/hello.fthr
```

Немесе:

```sh
make build
```

Компиляторды орындау үшін алдын ала құрастырылған x86-64 машиналық код бастапқы нұсқасы, Feather бастапқы коды және Linux стандартты жүйелік шақырулары ғана қажет. Қосымша shell скрипттері bash пен негізгі жүйелік утилиталарды пайдаланады. Орындау кезінде тілдік компилятор құралдарына тәуелділік жоқ. Бұл кросс-платформалық жүйе емес.

### Орнату

`~/.local/bin` бумасына орнату:

```sh
./scripts/install-linux.sh
```

Басқа орын үшін `PREFIX=/custom/path` орнатыңыз.

Нативті CLI екі позициялық аргумент қабылдайды:

```sh
feather SOURCE.feather OUTPUT.fthr
```

`feather build --maximum`, `feather inspect` және `feather lib` сияқты V7 командалары әлі көшірілмеген. Қолдау көрсетілмейтін аргументтермен `./bin/feather` шақыруына қолдау жоқ.

## Іске асырылған бастапқы жүктеу синтаксисі

Грамматика әдейі шектеулі:

```feather
#terminal-only
Working=demo
set r01=0000000000000000
set r02=0000000000000003
while r01<r02 [
say"Hello"
inc r01
]
quit.script
```

Айнымалылар `r00..r99` деп аталатын 100 64-биттік регистр ұяшығымен шектелген. `set` дәл 16 кіші әріппен жазылған оналтылық цифр қабылдайды. V7-дегі `set enabled=true` сияқты еркін идентификаторлар әлі қолдау таппайды.

Операциялар: `copy r01=r02`, `inc r01`, `dec r01`, `add r01=r02`, `sub r01=r02`, `mul r01=r02`.

Шарттар: `when r01==r02 [`, `when r01!=r02 [`, `when r01<r02 [`, `when r01>=r02 [`.

Циклдер: `while r01<r02 [`, `while r01!=r02 [`, `while r01==r02 [`; блоктар жеке жолдағы `]` таңбасымен жабылады.

### Шығыс, файлдар және бинарлық буферлер

- `say"ASCII/UTF-8 text"` — escape тізбектерін түсіндірмей және ішкі тырнақшаларды қолдамай мәтін шығарады.
- `load source` — argv кірісін бекітілген бастапқы код буферіне оқып, байт ұзындығын `r00` регистріне жазады.
- `store output rXX` — бинарлық шығысты келесі argv жолына жазады.
- `get r01=source[r02]` — байт оқиды.
- `get32 r01=output[r02]` — 32-биттік мән оқиды.
- `put output[r01]=r02` — байт жазады.
- `put32 output[r01]=r02` — 32-биттік мән жазады.
- `put64 output[r01]=r02` — 64-биттік мән жазады.
- `append r01="48454c4c4f"` — кіші әріппен берілген оналтылық байттарды қосады.
- `fail` — 2 шығу күйімен аяқталады.

Әр жолда бір нұсқау болуы керек; жол соңы LF, соңғы жол да LF таңбасымен аяқталуы тиіс. Жол басындағы `""` түсініктемелері және `Working=...` конструкциялары танылады. Жалпы V7 синтаксисі көшірілмеген.

Бұл — көшіруге арналған грамматика ішкі жиыны, Feather синтаксисімен толық үйлесімділік туралы мәлімдеме емес.

## Компилятор архитектурасы

Компилятор Feather тілінде жазылған және өзін-өзі құрастырады, бірақ қазір тікелей бір өтімді төмендетуді (direct one-pass lowering) орындайды. Жалпы AST, семантикалық талдағыш, оңтайландырғыш, жалпыланған типтер және IR әлі жоқ.

## Тексеру

`./scripts/test.sh` үш буынның байттық сәйкестігін, нативті ELF орындалуын, орындау кезіндегі арифметика мен циклдерді, 32/64-биттік бинарлық буфер операцияларын, NUL және `0xff` байттары бар файлдарды көшіруді, файл енгізу/шығару қателерін, қате бастапқы кодтың қабылданбауын және орындалмайтын стек метадеректерін тексереді. Rust немесе басқа тіл компиляторлары қолданылмайды.

### Бастапқы нұсқа және сенім түбірі

Seed — сенім түбірі болатын алдын ала құрастырылған машиналық код бағдарламасы. Ол бастапқыда осы бастапқы кодтар ағашынан тыс дайындалған. Алғашқы құрастырудан кейін компиляторды алдыңғы өзін-өзі құрастырған Feather орындалатын файлын пайдаланып, тек `src/compiler.feather` файлынан қайта өндіруге болады.

Буындар арасындағы хэштердің теңдігі тексерілген архитектурада детерминдік қайта жасалуды көрсетеді. Бұл зиянды әрекеттің жоқтығын, жад қауіпсіздігін немесе өндірістік деңгейдегі қорғанысты дәлелдемейді.

## Қалған маңызды миграция қадамдары

Тарихи функционалдық үшін ескі V7 архивін сақтаңыз. Нативті self-host тармағы әзірге атаулы айнымалыларды/Bool/мәтіндік өрнектерді, толық lexer/AST/типтер/IR жүйесін, типтелген сандық разрядтылықтарды, бастапқы код орындары бар компилятор диагностикасын, таңбалы сандардың толып кетуін тексеруді, GC-сіз жад қауіпсіздігі кепілдіктерін, автоматты шекара тексеруін, async, пакет менеджері/98 кітапхананы, `Number.by`, TLS/желіні, GUI/Blender/3D, FFI, `FTHRNAT2` пішімін, қолтаңбаларды, ARM64, Windows немесе fuzz/қауіпсіздік аудитін қолдамайды.

**Бұл нұсқаны сенімсіз бастапқы код үшін сенімді компилятор ретінде қолданбаңыз.** Бұл — тексерілген нативті self-host негізі, өндірістік пайдалануға дайын тіл дистрибутиві емес.
