# Feather Language — Незалежне самохостингове завантаження компілятора (v8, експериментальна версія)

Ця папка — дерево вихідного коду нового завантажувального компілятора Feather без Rust і зовнішніх залежностей. Вона не замінює всі можливості мови V7. Робочий архів V7 потрібно зберігати окремо, доки не буде досягнуто функціональної паритетності.

## Перевірені можливості, що працюють

Реалізація компілятора міститься у `src/compiler.feather` (завантажувальна підмножина Feather, приблизно 2300 рядків). Вона розпізнає токени й рядки, декодує числові операнди, структурно розв’язує прямі та зворотні переходи й безпосередньо генерує машинні інструкції x86-64 та заголовки Linux ELF64.

Нативний початковий компілятор x86-64 (`bootstrap/feather-seed`) компілює цей вихідний код Feather у другий нативний компілятор. Отриманий компілятор компілює той самий код у третій. Покоління побайтно ідентичні та мають однакові хеші SHA-256.

### `.feather -> .fthr`

У цій версії `.fthr` — виконуваний файл Linux ELF64 із розширенням `.fthr`, а не попередній контейнер V7 `FTHRNAT2`. Програма запускається безпосередньо в Linux, оскільки ELF є нативним контейнером ОС.

Для збирання та виконання не потрібні інтерпретатор, Rust, Cargo, Python, Clang, GCC, LLVM, glibc або JVM. Підтримку Windows, ARM64 і сумісність із форматом V7 не реалізовано.

Перший рядок має бути `#terminal-only`, `#executable` або `#script`. Останній рядок — `quit.script` із завершальним символом нового рядка. Усі три режими наразі створюють однакову консольну модель входу Linux ELF; семантику дозволів GUI/вікон не реалізовано.

### ELF і безпека

ELF статично скомпонований, без динамічного завантажувача, з окремими сегментами читання/виконання та читання/запису й невиконуваним стеком. Поточний ELF має тип `ET_EXEC`, не підтримує PIE/ASLR. Пісочниця для користувацького коду відсутня.

Арифметика регістрів використовує 64-бітні цілі числа з циклічним переповненням. Повної системи типів і автоматичної перевірки меж немає.

## Збирання без компіляторного інструментарію

У Linux x86-64 із цієї папки:

```sh
./scripts/build.sh
./scripts/test.sh
./bin/feather examples/hello.feather examples/hello.fthr
./examples/hello.fthr
```

Або:

```sh
make build
```

Потрібні лише готовий машинний код початкового компілятора x86-64, вихідний код Feather і стандартні системні виклики Linux. Необов’язкові shell-скрипти використовують bash і базові системні утиліти. Залежностей від мовних компіляторних інструментів під час виконання немає. Це не кросплатформна система.

### Встановлення

Для встановлення в `~/.local/bin`:

```sh
./scripts/install-linux.sh
```

Для іншого шляху задайте `PREFIX=/custom/path`.

Нативний CLI приймає два позиційні аргументи:

```sh
feather SOURCE.feather OUTPUT.fthr
```

Команди V7 `feather build --maximum`, `feather inspect` і `feather lib` ще не перенесено. Виклики `./bin/feather` з непідтримуваними аргументами не підтримуються.

## Реалізований синтаксис завантажувальної версії

Граматика навмисно обмежена:

```feather
#terminal-only
Working=demo
set r01=0000000000000000
set r02=0000000000000003
while r01<r02 [
say"Hello"
inc r01
]
quit.script
```

Змінні обмежені 100 слотами 64-бітних регістрів `r00..r99`. `set` приймає рівно 16 малих шістнадцяткових цифр. Ідентифікатори на кшталт V7 `set enabled=true` поки не підтримуються.

Операції: `copy r01=r02`, `inc r01`, `dec r01`, `add r01=r02`, `sub r01=r02`, `mul r01=r02`.

Умови: `when r01==r02 [`, `when r01!=r02 [`, `when r01<r02 [`, `when r01>=r02 [`.

Цикли: `while r01<r02 [`, `while r01!=r02 [`, `while r01==r02 [`; блоки закриваються `]` в окремому рядку.

### Виведення, файли та двійкові буфери

- `say"ASCII/UTF-8 text"` — виводить текст без інтерпретації escape-послідовностей і без вбудованих лапок.
- `load source` — читає аргумент argv у фіксований буфер вихідного коду й записує довжину в байтах у `r00`.
- `store output rXX` — записує двійкові дані за наступним шляхом argv.
- `get r01=source[r02]` — читає байт.
- `get32 r01=output[r02]` — читає 32-бітне значення.
- `put output[r01]=r02` — записує байт.
- `put32 output[r01]=r02` — записує 32-бітне значення.
- `put64 output[r01]=r02` — записує 64-бітне значення.
- `append r01="48454c4c4f"` — додає байти, задані шістнадцятковим рядком у нижньому регістрі.
- `fail` — завершує роботу з кодом 2.

Одна інструкція на рядок; переноси рядків — LF, останній рядок також має завершуватися LF. Розпізнаються коментарі `""` на початку рядка та конструкції `Working=...`. Загальний синтаксис V7 не перенесено.

Це міграційна підмножина граматики, а не твердження про повну сумісність із Feather.

## Архітектура компілятора

Компілятор написаний Feather і компілює сам себе, але наразі виконує безпосереднє одно-прохідне зниження (direct one-pass lowering). Загальна AST, семантичний аналізатор, оптимізатор, узагальнені типи та IR ще не реалізовані.

## Перевірка

`./scripts/test.sh` перевіряє три покоління побайтної відповідності самозбирання, виконання нативного ELF, арифметику й цикли під час виконання, операції з буферами 32/64 біт, копіювання файлів із байтами NUL/`0xff`, помилки файлового вводу-виводу, відхилення некоректного коду та метадані невиконуваного стека. Rust та інші компілятори мов не використовуються.

### Seed і корінь довіри

Seed — попередньо скомпільована машинна програма, що є коренем довіри. Спочатку її підготували поза цим деревом вихідного коду. Після першого збирання компілятор відтворюється з `src/compiler.feather` за допомогою попереднього самостійно зібраного виконуваного файла Feather.

Рівність хешів між поколіннями демонструє детерміноване відтворення на перевіреній архітектурі. Вона не доводить відсутності шкідливої поведінки, безпеки пам’яті чи готовності до промислового використання.

## Критичні етапи міграції, що залишилися

Зберігайте старий архів V7 для історичної функціональності. Нативна гілка self-host поки не підтримує іменовані змінні/Bool/текстові вирази, повний lexer/AST/типи/IR, типізовані числові ширини, діагностику з позиціями у вихідному коді, перевірку переповнення знакових чисел, гарантії безпечного керування пам’яттю без GC, автоматичну перевірку меж, async, менеджер пакетів/98 бібліотек, `Number.by`, TLS/мережу, GUI/Blender/3D, FFI, формат `FTHRNAT2`, підписи, ARM64, Windows або fuzz/аудит безпеки.

**Не розгортайте цю версію як довірений компілятор для недовіреного вихідного коду.** Це перевірена основа нативного self-host, а не готовий до промислового використання дистрибутив мови.
