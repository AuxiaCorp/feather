# Feather Language

**Feather** - компилируемый язык программирования общего назначения, ориентированный на производительность, предсказуемость и прямую работу с аппаратным обеспечением.

Feather разрабатывается как независимый язык с собственным синтаксисом, компилятором **LiteCompile** и нативной генерацией машинного кода для Linux x86-64.

Язык использует статическую типизацию, явное объявление переменных и функций, а также блочный синтаксис на основе квадратных скобок.

### Пример кода

```feather
task add(a: i64, b: i64) returns i64 [
    return a + b
]

task main() returns i64 [
    result: i64 = add(10, 20)
    return result
]
```

### Основные особенности

- **Нативная компиляция.** Генерация исполняемого машинного кода без виртуальной машины и интерпретатора.
- **Статическая типизация.** Проверка типов на этапе компиляции.
- **Простой синтаксис.** Функции объявляются через `task`, блоки кода заключаются в `[` и `]`.
- **Низкоуровневый контроль.** Ориентация на системное программирование и предсказуемое выполнение.
- **Собственный компилятор.** LiteCompile разрабатывается на Feather без зависимости от LLVM, GCC или Clang.
- **Самокомпиляция.** Архитектура проекта предусматривает сборку компилятора из его собственных исходников.

### Компиляция

Исходные файлы Feather используют расширение `.feather`, а результат компиляции - `.fthr`.

```bash
lite -B main.feather
```

### Текущее состояние

Feather находится в активной разработке. Ветка V9 развивает систему функций, типизацию, генерацию нативного кода и механизм самокомпиляции. Часть возможностей ещё находится на стадии реализации и тестирования.

**Цель проекта** - создать самостоятельный компилируемый язык для разработки нативных программ с минимальной зависимостью от сторонних инструментов.
